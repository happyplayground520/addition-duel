# 數學遊樂園

給小朋友玩的數學小遊戲合集。打開網址會先看到遊樂園地圖，點任何一個設施就能直接進去玩。

| 設施 | 玩法 |
| --- | --- |
| 🎪 搶答對決 | 兩人坐在平板兩側，搶答 10 以內的加減法，有數字題和附注音的應用題 |
| 🚗 碰碰車 | 兩人賽跑，各自選難度、各答各的題目，答對車子前進，先到終點贏；難度不同時只念難度低那邊的題目 |
| 🚂 小火車 | 兩人輪流擲骰子，答對自己難度的題目才能前進，有加速站和隧道，先繞一圈的贏 |
| 🎈 射氣球 | 一人玩，聽題目，戳破寫著正確答案的氣球 |
| 🎠 旋轉木馬 | 一人玩，認識時鐘：看鐘選時間，或拖動長針短針撥到指定時間 |
| 🎡 摩天輪 | 一人玩，乘法：幾個車廂、每個車廂坐幾隻動物，總共幾隻 |
| 🎟️ 售票亭 | 一人玩，認識錢幣：用新臺幣硬幣和紙鈔付剛好的門票錢 |
| 🍩 甜甜圈攤 | 一人玩，乘法排排看：看盤子上幾排、每排幾個算總數，或自己把甜甜圈排進盤子 |
| ⭕ 套圈圈 | 一人玩，九九乘法限時快答，把圈圈丟到答案的瓶子上，記錄最佳成績 |
| 🐠 撈金魚 | 一人玩，限時把所有等於目標數字的金魚撈進水桶（數的合成分解、加減），記錄最佳成績 |
| 🧸 夾娃娃機 | 一人玩，限時夾娃娃：算算看（算出答案，夾寫著答案的娃娃）、比大小（夾出所有比某數大或小的娃娃），記錄最佳成績 |
| 🃏 翻牌湊十 | 兩人輪流翻牌，兩張加起來湊成 5 或 10 就拿走，拿最多對的人贏 |
| 🔷 形狀搶答 | 兩人各自找出指定形狀的東西（平面：三角形、圓形、正方形、長方形；立體：球體、圓柱體、正方體、長方體、圓錐體），先集滿 10 顆星贏 |
| 🎢 雲霄飛車 | 一人玩，限時倒數，從衝下來的車廂裡找出答案等於目標數字的算式，會記錄最佳成績 |

- 題目會用語音念出來，可選擇聲音與語速（在搶答對決的設定裡選，射氣球也會沿用）
- 運算可勾選：只出加法、只出減法，或加減混合
- 難度可選：初級（1–10）、進階（1–20）、高級（1–100），三個遊戲共用同一個設定

## 🏴‍☠️ 海盜灣（英文區）

從遊樂園地圖左上角的海盜船開船過去，給小一孩子練習熟悉英文。畫面上盡量只有英文和圖示，每個遊戲都有「🔊 中文說明」；英文用美式發音、慢慢念。玩完拿到的金幣可以幫鸚鵡買帽子。

| 地點 | 玩法 |
| --- | --- |
| 🎣 碼頭釣魚 | ⭐ 聽單字，釣出身上寫著這個字的魚；⭐⭐ 聽單字，釣出有這個圖的魚；⭐⭐⭐ 看圖（不念），釣出寫著這個字的魚。主題：動物、食物、顏色、數字、交通與玩具 |
| 📦 寶箱與鸚鵡 | 聽句子把東西拖到寶箱的 on／in／under（⭐⭐ 加 next to，⭐⭐⭐ 加 left／right，並有「Where is…?」選英文字） |
| 💎 藏寶圖字母 | ⭐／⭐⭐ 把寶石拖進對的鎖孔，大寫配小寫（⭐⭐ 有 b／d／p／q 這種容易混的字）；⭐⭐⭐ 在四線格上寫出大寫或小寫，寫錯會出現虛線讓孩子描 |
| 📖 船長說故事 | 繪本一句一句念，念到哪句亮哪句；聽完回答 Who（⭐⭐ 加 What，⭐⭐⭐ 加 When），點英文字聽、選好按 OK |
| 🦜 鸚鵡拼字 | ⭐ 看圖聽字補第一個字母；⭐⭐ 把三個字母積木排成單字；⭐⭐⭐ 沒有圖只用聽的，四五個字母，還多放用不到的字母 |
| 💬 港口聊天 | 鸚鵡連續問三個問題（How are you?／How's the weather?／How old are you?），看表情、窗外天氣、蛋糕蠟燭，選出要回答的那句話；⭐⭐⭐ 泡泡上沒有字，只能用聽的 |
| 🏠 船長的家 | 「Where is the …?」打開對的房間門（kitchen、bedroom、living room、bathroom），再點出那個東西；⭐⭐⭐ 改成「I want to sleep.」這種要做的事 |

## 🍰 甜點小鎮（國字練習）

從遊樂園地圖左上角的蛋糕進去。可以選 A 版或 B 版（一年級上學期），再選從第幾課練到第幾課。題目裡的國字用全字庫正楷體；句子都有注音，要考的字和選項不加注音。

| 地點 | 玩法 |
| --- | --- |
| 🍪 餅乾模子 | 選出字的部首（照教育部的部首原形，例如「艸」「水」），選項有注音，也會放字裡看得到、但不是部首的部件 |
| 🍬 數糖果 | 選出字有幾畫（筆畫以教育部《國字標準字體筆順學習網》為準），答完一畫放一顆糖果數一數，並可以開啟教育部的筆順頁 |
| 🥐 麵包店送貨 | 句子少一個字，選出對的字（生字和認讀字） |
| 🧋 冰火飲料店 | 找出意思相反的字；沒學過的字會加注音 |

之後會再加：點餐櫃台（說出造詞）、蛋糕寫字（看注音寫國字）、擺餐桌（看圖擺位置）、挑壞蘋果（找錯字、形近字）、市場秤一秤（量詞）、音樂甜筒（注音聲調）、串糖葫蘆（句子重組）、午茶說故事（成語故事）。

資料來源：生字為教育部教育百科「生字詞彙表」；部首、讀音為教育部《國語辭典簡編本》；筆畫為教育部《國字標準字體筆順學習網》。字型為全字庫正楷體（數位發展部「CNS11643中文標準交換碼全字庫」，依政府資料開放授權條款第1版使用），只保留遊戲用到的字。資料檔由 `town/build.js` 產生，四關頁面由 `town/pages.py` 產生。
