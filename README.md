# 數學遊樂園

給小朋友玩的數學小遊戲合集。打開網址會先看到遊樂園地圖，點任何一個設施就能直接進去玩。

| 設施 | 玩法 |
| --- | --- |
| 🎪 搶答對決 | 兩人坐在平板兩側，搶答 10 以內的加減法，有數字題和附注音的應用題 |
| 🚗 碰碰車 | 兩人賽跑，各自選難度、各答各的題目，答對車子前進，先到終點贏；難度不同時只念難度低那邊的題目 |
| 🚂 小火車 | 兩人輪流擲骰子，答對自己難度的題目才能前進，有加速站和隧道，先繞一圈的贏 |
| 🎈 射氣球 | 一人玩，聽題目，戳破寫著正確答案的氣球 |
| 🎠 旋轉木馬 | 一人玩，認識時鐘：看鐘選時間，或拖動長針短針撥到指定時間 |
| 🎡 摩天輪 | 一人玩，乘法：幾個車廂、每個車廂坐幾隻動物，總共幾隻 |
| 🎟️ 售票亭 | 一人玩，認識錢幣：用新臺幣硬幣和紙鈔付剛好的門票錢 |
| 🍩 甜甜圈攤 | 一人玩，乘法排排看：看盤子上幾排、每排幾個算總數，或自己把甜甜圈排進盤子 |
| ⭕ 套圈圈 | 一人玩，九九乘法限時快答，把圈圈丟到答案的瓶子上，記錄最佳成績 |
| 🐠 撈金魚 | 一人玩，限時把所有等於目標數字的金魚撈進水桶（數的合成分解、加減），記錄最佳成績 |
| 🎢 雲霄飛車 | 一人玩，限時倒數，從衝下來的車廂裡找出答案等於目標數字的算式，會記錄最佳成績 |

- 題目會用語音念出來，可選擇聲音與語速（在搶答對決的設定裡選，射氣球也會沿用）
- 運算可勾選：只出加法、只出減法，或加減混合
- 難度可選：初級（1–10）、進階（1–20）、高級（1–100），三個遊戲共用同一個設定

線上玩：https://happyplayground520.github.io/addition-duel/
