# 數學遊樂園

給小朋友玩的數學小遊戲合集。打開網址會先看到遊樂園地圖，點任何一個設施就能直接進去玩。

| 設施 | 玩法 |
| --- | --- |
| 🎪 搶答對決 | 兩人坐在平板兩側，搶答 10 以內的加減法，有數字題和附注音的應用題 |
| 🎈 射氣球 | 一人玩，聽題目，戳破寫著正確答案的氣球 |
| 🎠 旋轉木馬 | 建造中 |
| 🎡 摩天輪 | 建造中 |
| 🎢 雲霄飛車 | 一人玩，限時倒數，從衝下來的車廂裡找出答案等於目標數字的算式，會記錄最佳成績 |

- 題目會用語音念出來，可選擇聲音與語速（在搶答對決的設定裡選，射氣球也會沿用）
- 運算可勾選：只出加法、只出減法，或加減混合
- 難度可選：初級（1–10）、進階（1–20）、高級（1–100），三個遊戲共用同一個設定

線上玩：https://happyplayground520.github.io/addition-duel/
